# Hemle Crew

*Connecter les développeurs africains avec l'esprit du Hemle.*

**Hemle** vient du bassa, une langue du Cameroun : le courage, la foi, un esprit combatif qui ne cède pas.

Nous participons à la **CADEV 2026** (Compétition Africaine des Développeurs, organisée par Systalink) avec un objectif : construire la plateforme d'échange africaine, pour les devs, par les devs.
